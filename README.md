# Notchcue releases

Signed and Apple-notarized macOS builds of **Notchcue** — a menu-bar teleprompter
that sits right under your camera and keeps you on script while you look at the lens.

Downloads live on the [Releases](../../releases) page. The source repository stays
private. Notchcue is an independent MIT-licensed fork of
[CueFlow](https://github.com/binghe1980/cueflow), itself a derivative of
[NotchPrompt](https://github.com/saif0200/notchprompt).

- Website: https://notchcue-landing.pages.dev
- Appcast: https://notchcue-landing.pages.dev/appcast.xml (Sparkle auto-update)
- Requirements: macOS 14 or later, Apple Silicon or Intel
